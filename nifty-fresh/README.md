# 📈 NIFTY Normal Distribution Visualizer

🔧 Backend Setup (Flask):
# Setup virtual environment
python3 -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Place CSVs in /database (format: Date, Close, etc.)
python nifty_backend_api.py

💻 Frontend Setup (React):
cd frontend
npm install
npm start
